# 📚 E-Library Website

An interactive and user-friendly **E-Library system** built for HPTU  university students to explore, view, and download books organized by department. The project focuses on clean design and accessibility for enhanced digital learning. Built with a clean UI and basic functionality to enhance digital learning access.

## 🌟 Features

- 🖼️ **Book cover gallery** with a clean, visual layout
- 🗂️ **Department-wise book organization** for easy navigation
- 🔍 Simple and intuitive **user interface**
- 💻 Built using **HTML, CSS, Bootstrap**
- 🧩 Backend compatibility using **PHP & MySQL**
## 🚀 Technologies Used
- HTML5  
- CSS3 / Bootstrap  
- JavaScript *(optional)*  
- PHP / MySQL *(if backend is added)*  
- XAMPP for local hosting
